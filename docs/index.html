C2-Lite

Educational client-server architecture prototype for studying agent check-ins, task queues and process communication in an isolated lab.

Source repositoryTechnical notes and limitations
Experimental and intentionally incomplete. The current task flow permits server-delivered commands to be executed by an agent. It lacks robust agent authentication, task authorization, process isolation and complete end-to-end protection. It must not be exposed to public or corporate networks.

Prototype client that polls for task state. The execution model is deliberately documented as unsafe outside a disposable lab.
